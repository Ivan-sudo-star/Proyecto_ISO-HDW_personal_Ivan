# Rúbrica d'autoavaluació individual

Estat actual: **69 de 78** accions Apte i **13 de 18** Apte+. Totes les que falten són de la prova del 25/11 (Tasca 8).

| Fitxer | Què és | Cal fer-hi res? |
|---|---|---|
| [`Rubrica-autoavaluacio-Individual-Ivan.html`](Rubrica-autoavaluacio-Individual-Ivan.html) | **La rúbrica amb les meues marques posades.** S'obri amb el navegador: mostra cada acció, si està feta i les observacions per tasca | És la que s'ensenya al professor |
| [`seguiment-individual-Ivan.txt`](seguiment-individual-Ivan.txt) | Fitxer de seguiment en el format de la rúbrica del professor (*«Obri fitxer»*): carrega les marques a la rúbrica original | Només si el professor demana el fitxer de seguiment |
| [`original/`](original/) | La rúbrica del professorat tal com està a Aules, sense tocar | No |
| [`estat.json`](estat.json) | Les marques (1 = fet) i les observacions de cada tasca | S'edita quan es fa una acció nova |
| [`actualitza-rubrica.py`](actualitza-rubrica.py) | Genera els dos primers fitxers a partir de l'original i d'`estat.json` | `python3 rubrica/actualitza-rubrica.py` després de canviar `estat.json` |

Només es marca una acció quan hi ha evidència real al repositori.
